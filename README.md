# Corner Space

ระบบรับรถและจัดการงานคิว สำหรับร้าน Corner Space (คาร์ดีเทลลิ่ง ฟิล์มกรองแสง ฟิล์มใสกันรอย)

- `index.html` : แอปทั้งหมดในไฟล์เดียว (เวอร์ชันที่ใช้งานอยู่ใน Claude Artifact)
- ใช้งานเต็มรูปแบบ (ฐานข้อมูลกลาง, อ่านรูปด้วย AI, สิทธิ์เจ้าของ) ต้องรันภายใน Claude Artifact
- ถ้าเปิดไฟล์นอก Claude ข้อมูลจะเก็บเฉพาะในเบราว์เซอร์เครื่องนั้น

แผนต่อไป: ย้ายเป็นแอปของร้านเอง (Firebase + LINE LIFF + Claude API)
